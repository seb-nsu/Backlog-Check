# backlog-check

Prüft einen Backlog gegen feste Regeln, bevor Stories in die Umsetzung gehen: fehlende Akzeptanzkriterien, nicht prüfbare Kriterien, zu große Stories, versteckte Abhängigkeiten, Zyklen, mögliche Dubletten und Widersprüche. Jeder Befund nennt die Regel und die Textstelle. Das Paket enthält keine KI und braucht nur die Python-Standardbibliothek.

> **English:** Checks a backlog against fixed rules before stories go into delivery: missing or unmeasurable acceptance criteria, oversized stories, hidden dependencies, cycles, possible duplicates and contradictions. Every finding names its rule and the place in the text. No AI, standard library only. The concept is written in German.

**Stand:** Konzept freigegeben, Umsetzung noch nicht begonnen.
